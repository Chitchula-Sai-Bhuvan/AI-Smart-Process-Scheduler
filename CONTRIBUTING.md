# Contributing

Thanks for your interest! Short guidelines to make contributions review-ready.

- Create an issue first to discuss larger changes.
- Fork the repo and open a PR against `main` with a concise description and screenshots if applicable.
- Keep commits small and focused; use descriptive commit messages.
- Follow the existing Java style and Python formatting (PEP8). Run `black` for Python changes where applicable.
- Add unit tests for bug fixes and features where possible.

Maintainer tips: run the Java examples and the Python `train_model.py` locally to reproduce reported results.
